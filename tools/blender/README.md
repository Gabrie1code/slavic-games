# Генерация 3D-моделей скриптами Blender

Модели окружения создаются Python-скриптами через модуль `bpy` (Blender как библиотека).
Скрипт строит модель, экспортирует её в `.glb` и по желанию рендерит превью.

## Установка (один раз)
Модулю `bpy` 4.2 нужен Python 3.11:

```bash
uv venv -p 3.11 .bvenv
uv pip install -p .bvenv/bin/python "bpy==4.2.0"
```

## Запуск
```bash
.bvenv/bin/python tools/blender/soviet_tv.py assets/models/props --render
```

## Правила для моделей
- Стиль: стилизованный low-poly, плоское затенение, однотонные материалы без текстур.
- Масштаб: 1 единица = 1 метр. Модель стоит на полу (z = 0 в Blender).
- Перед модели смотрит в −Y в Blender, после экспорта это +Z в Godot.
- Бюджет: предмет до ~2 000 треугольников, крупный объект до ~10 000.
