# Картинки карточек мини-игр

Сюда кладутся картинки для рулетки мини-игр. Имя файла = id мини-игры:

| Файл | Мини-игра |
|---|---|
| `sausage_queue.png` | Очередь за колбасой |
| `bat_battle.png` | Битва на битах |
| `freeze_tag.png` | Морожка |

Формат: PNG, вертикальный 3:4 (например 900×1200). Название игра подпишет сама
на тёмной плашке внизу, поэтому на картинке текст не нужен — оставьте низ спокойным.
Пока файла нет, карточка показывается с текстом.
